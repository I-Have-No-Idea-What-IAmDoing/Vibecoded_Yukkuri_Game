## 2024-05-22 - Fixing Button Theming in PygameGUI **Learning:** `pygame_gui` themes using `element.class` require `object_id=ObjectID(class_id="class_name")`, not just `object_id="class_name"` (which sets the ID). Always verify theme selectors in `ui_theme.json`. **Action:** Use `ObjectID` for class-based styling.
## 2026-01-28 - PygameGUI Mocking Limits **Learning:** `pygame_gui.UIManager` mocks in tests may fail if methods like `get_window_resolution` are missing from the spec. **Action:** Prefer using stored layout dimensions (e.g., `layout.width`) or explicit values in tests instead of relying on manager methods.
